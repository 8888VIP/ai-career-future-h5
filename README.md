# AI时代·孩子未来职业推演 H5

面向6—15岁孩子家长的引导式对话H5。当前版本为纯前端、无外部依赖的可运行产品，结果基于家长选择在浏览器本地即时生成。

## 运行

```powershell
cd C:\Users\Administrator\Documents\1111\ai-career-future-h5
python -m http.server 4173
```

浏览器打开：`http://127.0.0.1:4173/`

## 已实现

- 首屏结果预览与隐私说明
- 7轮引导式AI对话
- 9种常见家长期待职业分支
- 10类日常兴趣线索，包含策略闯关、虚拟探索、体能挑战和团队竞技
- 职业任务拆解卡
- 基于真实回答回指的能力证据卡
- 三个可探索方向
- 可勾选的7天家庭任务
- AIGC体验课与企业微信承接弹层
- 企业微信二维码查看与保存
- 两页中文PDF结果报告生成与下载
- 手机与桌面响应式布局

## 数据与隐私

- 不收集孩子姓名、学校、照片或联系方式。
- 家长的选择与结果只在当前浏览器中即时处理。
- PDF在浏览器本地生成，不上传家长填写的内容。

## 文件

- `index.html`：页面结构
- `styles.css`：响应式视觉
- `app.js`：对话分支、职业数据、能力线索与结果生成
- `assets/wecom-qr.jpg`：天马老师企业微信二维码
- `verify.ps1`：本地静态验证
- `browser-test.py`：Edge浏览器端到端交互验证与截图
- `rollback.ps1`：将指定项目副本移入回滚归档目录
